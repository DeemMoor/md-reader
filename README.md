# MD Reader

Лёгкая читалка Markdown-файлов для Windows на Rust. Показывает `.md` так, как он выглядит на GitHub, а не голым текстом, как в Блокноте.

## Возможности

- Разметка в стиле GitHub: **жирный**, *курсив*, ~~зачёркнутый~~, `код`, таблицы, сноски[^1]
- Подсветка синтаксиса в блоках кода
- Светлая и тёмная тема (переключается вслед за системной)
- Автообновление, когда файл меняется на диске
- Картинки по относительным путям, переходы по ссылкам между `.md` файлами
- Внешние ссылки открываются в браузере

## Управление

| Действие             | Как                                 |
|----------------------|-------------------------------------|
| Открыть файл         | <kbd>Ctrl</kbd> + <kbd>O</kbd> или перетащить в окно |
| Поиск по тексту      | <kbd>Ctrl</kbd> + <kbd>F</kbd>       |
| Масштаб              | <kbd>Ctrl</kbd> + колесо мыши        |
| Назад                | <kbd>Alt</kbd> + <kbd>←</kbd>        |
| Обновить             | <kbd>F5</kbd>                        |

## Сборка

```powershell
cargo build --release
```

Готовый файл: `target\release\mdreader.exe`. Можно открыть файл сразу:

```rust
fn main() {
    let path = std::env::args().nth(1).unwrap_or_default();
    println!("mdreader.exe {path}");
}
```

> [!TIP]
> Чтобы `.md` открывались двойным кликом: ПКМ по файлу → «Открыть с помощью» → «Выбрать другое приложение» → указать `mdreader.exe` и поставить галочку «Всегда использовать».

> [!NOTE]
> Если запустить читалку с правами администратора, перетаскивание файлов из Проводника работать не будет — Windows блокирует drag&drop из обычных программ в повышенные. Используйте <kbd>Ctrl</kbd> + <kbd>O</kbd> или запускайте как обычно.

> Обычная цитата тоже выглядит прилично.
